# 08｜測試圖片命名與匯入規格

## 1. 你需要準備的素材（第一批 5～10 隻）

| 素材 | 數量 | 說明 |
|---|---|---|
| 正式角色插畫 PNG | 每隻 1 張 | 透明背景 |
| 剪影 PNG | 每隻 1 張（或由程式自動產生，D-22） | 透明背景、單色 |
| 角色配方對照表 | 1 份 | 用下方 CSV 格式填寫 |
| 元素清單 | 1 份 | 元素 ID、名稱、分類、圖示 |
| 元素圖示 | 每種元素 1 張 | 透明 PNG |
| 法鬥好朋友 Logo | 1 張 | 透明 PNG，收藏卡用 |

## 2. 角色 ID 與圖鑑編號

| 項目 | 建議格式 | 範例 | 規則 |
|---|---|---|---|
| 角色 ID | `fm` + 三位數 | `fm001` | 小寫英數、固定不變、永不重用 |
| 圖鑑編號 | 1～100 | `1`（畫面顯示 `001`） | 唯一 |

> 建議第一版讓角色 ID 的數字與圖鑑編號相同（`fm001` ↔ 001），方便你對照。
> 但兩者在資料庫中是**分開的欄位**，日後若需要調整圖鑑排序，只改編號、不改 ID，玩家收藏不受影響。
> 若你偏好其他 ID 格式（例如英文名 slug），請在 D-23 告訴我。

## 3. 檔案命名

交給我的原始檔請放在同一個資料夾，命名如下：

```
frenchie-assets/
├─ characters/
│  ├─ fm001.png          ← 正式插畫
│  ├─ fm001_sil.png      ← 剪影（若選擇手繪剪影）
│  ├─ fm002.png
│  └─ ...
├─ elements/
│  ├─ moon_dew.png       ← 檔名 = 元素 ID
│  └─ ...
├─ brand/
│  └─ logo.png
├─ characters.csv
├─ elements.csv
└─ recipes.csv
```

規則：

- 全部小寫英文、數字、底線；不使用中文、空白、大寫。
- 副檔名一律 `.png`（小寫）。
- 不要在檔名放角色中文名稱（避免從檔名得知未解鎖角色）。

## 4. 對照表格式（CSV，UTF-8）

**`characters.csv`**

```csv
character_id,dex_no,name_zh,art_file,silhouette_file,note
fm001,1,（角色名稱）,fm001.png,fm001_sil.png,
```

**`elements.csv`**

```csv
element_id,name_zh,category_id,category_name_zh,icon_file,max_stack
moon_dew,（元素名稱）,liquid,（分類名稱）,moon_dew.png,
```

`max_stack` 可先留空，待 D-02 決定。

**`recipes.csv`**（一列一個配方，步驟用 `元素ID*數量` 以 `|` 分隔）

```csv
recipe_id,character_id,scene_id,steps,note
r_fm001_a,fm001,cauldron,moon_dew*2|star_sugar*1|moon_dew*1,
```

`scene_id`：`cauldron`（魔女魔法鍋）、`dessert_bowl`（甜點鋼盆）、或留空表示不限（依 D-07）。

分類步驟以 `@` 開頭，例如 `@cream*2`（D-27：同一步內可混用同分類的不同元素）。

> 實際的第一批資料檔在 [`content/`](../../content/README.md)，格式與這裡相同（多了 `status`、`idea` 等說明欄位）。

> 用 Google 試算表或 Excel 填寫後「下載為 CSV（UTF-8）」即可。範例中的元素與配方都只是格式示範。

## 5. 圖片技術規格

| 項目 | 規格 | 狀態 |
|---|---|---|
| 格式 | PNG，RGBA（有透明通道） | ✅ |
| 色彩空間 | sRGB | 建議 |
| 畫布比例 | 正方形，角色置中，四周留白一致 | 建議 |
| 尺寸 | 例：1024×1024 或 2048×2048 | ⏳ D-14 |
| 單檔大小 | 例：≤ 2 MB（過大時匯入工具另產生壓縮版） | ⏳ D-14 |
| 剪影 | 與原圖相同尺寸、相同位置，單一顏色 | ⏳ D-22 |

## 6. 批次匯入檢查清單（Phase 2 匯入腳本會自動檢查）

匯入工具在本機執行、使用 `service_role` 金鑰（只存在你電腦的 `.env`，不進 Git），任一項失敗就**整批不匯入**：

- [ ] 三份 CSV 都能用 UTF-8 正確讀取，欄位名稱正確。
- [ ] `character_id` 符合格式且不重複；`dex_no` 介於 1～100 且不重複。
- [ ] 每個 `art_file`、`silhouette_file`、`icon_file` 檔案都存在；沒有多餘未登記的檔案。
- [ ] 每張 PNG 都有透明通道、尺寸與大小符合規格。
- [ ] 剪影與原圖尺寸一致。
- [ ] 配方中的每個元素 ID 都存在於 `elements.csv`。
- [ ] 配方相鄰步驟沒有重複元素、`qty ≥ 1`、總投入數不超過場景上限（D-08）。
- [ ] 同場景沒有兩個相同的配方。
- [ ] 每隻角色至少有一個配方。
- [ ] 初始元素至少能完成一個配方（見 05）。
- [ ] 匯入前顯示摘要（新增幾隻、更新幾隻），你確認後才上傳。
- [ ] 匯入後自動抽查：未登入時無法讀取任一正式插畫。

重複匯入同一批資料時，結果應相同（以 ID 為準更新，不產生重複資料）。
