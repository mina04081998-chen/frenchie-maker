## 可以試的流程

| 流程 | 怎麼走 |
|---|---|
| 訪客試玩 | 歡迎頁 →「先以訪客試玩看看」→ 投料 → 開始製造（不會做出正式法鬥） |

| 製造 | 製造所 → 切換攪拌盆／魔法缸 → 點選元素（不看順序）→ 鍋子上方浮現可能的角色剪影 → 開始製造 |
| 圖鑑 | 未解鎖顯示剪影＋編號＋？？？；解鎖後顯示正式插畫與資料 |
| 分享 | 角色詳情 → 分享 → 收藏卡／透明 PNG |
| 每日補給 | 補給分頁 → 領取（馬鈴薯 2 ＋ 隨機 4 個）；已領取顯示下次 05:00 倒數 |
| 帳號 | 登出、登入、忘記密碼（模擬寄信與點連結） |
| 原型工具 | 我的 → 跳到明天、每種食材 +5、清除所有原型資料 |

可以用來測試成功的配方：教學的南瓜，以及 `content/recipes.csv` 裡的另外 4 個（D-34 已確認）。初始元素只夠做南瓜、藍衣乳牛、小花；要試熱狗和螃蟹，先到「我的 → 每種食材 +5」。

場景使用你提供的兩張插畫（`src/assets/scenes/`）。鍋子區會固定在畫面上方，往下選元素時仍看得到浮現的剪影。

場景動畫（`src/components/SceneFx.tsx`）：攪拌盆有旋轉的漩渦與往上飄的蒸氣；魔法缸有冒出的泡泡與呼吸的光暈；兩邊都有閃爍的小星星。放入元素時，元素會掉進盆／缸口並泛起漣漪；按下「開始製造」時動畫會加速。系統設定「減少動態效果」時會停用動畫。

## 視覺風格（已確認）

日系繪本風、可愛簡約，只用淺色底。色彩都定義在 `src/styles.css` 開頭的 `:root`。

| 用途 | 色彩 |
|---|---|
| 底色（和紙白） | `#FFFCF6` |
| 線框（墨灰，3px） | `#3E3A39` |
| 珊瑚粉：主要按鈕、選中狀態 | `#F2A497` |
| 山吹黃：提示、新角色徽章、進度條 | `#F6D27A` |
| 水色：原型標籤、未解鎖底色 | `#A8D3E6` |
| 若竹綠：試玩提示、標籤 | `#B9DAA5` |

- 大圓角（24px／32px）、平塗，不使用漸層與深色底。
- 字型只用 Google Fonts「Huninn」（粉圓體，單一字重，不使用粗體）。
- 食材圓圈的顏色是各色系的代表色（D-28），不屬於介面配色。

## 與正式版的差異（Phase 2 會處理）

- **配方答案在前端程式裡**（`src/api/mockServerData.ts`）。Phase 2 起只放在資料庫，前端拿不到。
- **正式插畫打包在前端**（縮小的 webp）。Phase 2 起改放 Supabase 私有 bucket，以簽名網址讀取。
- 帳號密碼以明文存在瀏覽器，只供試玩；請勿使用真實密碼。
- 每日補給的抽獎與遊戲日由前端模擬；正式版由伺服器判定。

## 架構重點

- `src/api/types.ts` 定義畫面與伺服器之間的介面；Phase 2 只要用 Supabase 實作同一介面，畫面程式不用改。
- 假伺服器 `src/api/mockApi.ts` 已照規格實作冪等（同一個 requestId 只扣料一次）、持有上限、成功失敗都扣料。
- 配方比對採逐格比對（`src/lib/recipe.ts`），與 Phase 0 文件一致。
- 場景只影響畫面，不傳入比對（D-07）。

## 本機執行

需要 Node.js 20.19 以上（建議 24 LTS）。

```bash
npm install
npm run dev      # 開發模式，網址顯示在終端機
npm run build    # 建置到 dist/
npm run lint     # 程式檢查
```

用手機連同一個 Wi-Fi 測試：`npm run dev -- --host`，再用手機開終端機顯示的 `Network` 網址。
