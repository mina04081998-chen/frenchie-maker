## `art/clean/` 的處理內容

| 角色 | 處理 |
|---|---|
| fm001 | 無變更 |
| fm002 | 移除 `Yummy :)` 字樣 |
| fm003 | 移除 `wink` 字樣 |
| fm004 | 移除畫面下方 1 個極小雜點（279 像素） |
| fm005 | 移除 2 個極小雜點（12 像素） |

處理方式：只保留圖中最大的一塊連續圖形（角色本體），其餘分離的圖形都移除。角色本體的像素完全沒有改動。

## 配方 `steps` 寫法

- `元素ID*數量`，項目之間用 `|` 分隔。**不看順序**。
- `@分類ID*數量` 表示「該分類的任意元素」，同一步內可混用（D-27）。
  例：`@cream*2` → 投「馬鈴薯＋奶油」、「奶油＋奶油」都算對。
- 每個配方至少要有一步 `potato*N`（馬鈴薯規則）。
- 配方不含場景（D-07）。
