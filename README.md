# 法鬥製造所 Frenchie Maker

手機優先的網頁收集遊戲：依固定的食物元素配方與投入順序，製造法鬥並收進圖鑑。品牌：法鬥好朋友。

> ⚠️ 本儲存庫含正式角色插畫，必須保持 **Private**。

## 目前階段：Phase 1（前端原型，使用假資料）

說明與試玩方式見 [`docs/phase1/README.md`](docs/phase1/README.md)。

```bash
npm install
npm run dev
```
